# Przykładowe dokumenty

`umowa-najmu.docx` i `umowa-najmu.pdf` to ta sama umowa najmu z kilkoma niedozwolonymi zapisami (§ 5–9), do pokazu wgrywania plików i do ewaluacji. Dane osobowe są fikcyjne, ale mają poprawne sumy kontrolne (PESEL, dowód osobisty, IBAN), więc anonimizacja powinna je wszystkie usunąć.
