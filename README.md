# LegAid

Asystent AI do analizy umów i pism prawnych według prawa polskiego. Wskazuje ryzykowne i niezgodne z prawem zapisy, wyjaśnia je prostym językiem i proponuje poprawki. Na razie to API w ASP.NET Core (.NET 10) z modelem OpenAI; jak uruchomić: [docs/DEMO.md](docs/DEMO.md).
