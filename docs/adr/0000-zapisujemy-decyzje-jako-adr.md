# ADR-0000: Zapisujemy decyzje architektoniczne jako ADR-y

- Status: Zaakceptowana
- Data: 2026-11-16

## Decyzja

Każdą ważną decyzję o architekturze zapisujemy jako krótki ADR w `docs/adr/`, w osobnym, numerowanym pliku. Zaakceptowanych ADR-ów nie zmieniamy. Gdy zmieniamy zdanie, piszemy nowy ADR, a staremu zmieniamy status na „Zastąpiona przez ADR-XXXX”.

## Konsekwencje

Po czasie wiadomo, dlaczego coś jest zrobione tak, a nie inaczej, i jakie były alternatywy.
